Kebijakan Privasi

Terakhir diperbarui: 11 Oktober 2026

1. Penyimpanan Data

Mizan Okane dirancang dengan prinsip bahwa data keuangan Anda adalah milik pribadi Anda sepenuhnya. Data disimpan dengan cara berikut:

  • Penyimpanan Lokal (IndexedDB): Seluruh data transaksi, dompet, kategori, dan budget disimpan langsung di perangkat Anda menggunakan IndexedDB browser. Data ini memungkinkan aplikasi berfungsi penuh saat offline (tanpa koneksi internet).
  • Folder Tersembunyi Google Drive (appDataFolder): Jika Anda mengaktifkan sinkronisasi Google Drive, berkas data cadangan disimpan di folder khusus aplikasi yang tersembunyi (appDataFolder) di akun Google Drive milik Anda sendiri.

2. Tidak Ada Server Pihak Ketiga

Aplikasi ini berjalan sepenuhnya di sisi klien (client-side) tanpa server perantara atau server pihak ketiga.

Pengembang aplikasi tidak dapat melihat, menyimpan, mengumpulkan, ataupun mengirim data keuangan pengguna ke mana pun. Semua proses pengolahan data transaksi berlangsung langsung di perangkat Anda.

3. Penggunaan Akun Google dan Izin (Scope)

Login Google bersifat opsional dan hanya dipakai untuk keperluan sinkronisasi data antar perangkat Anda.

Izin (OAuth scope) yang diminta oleh aplikasi:

https://www.googleapis.com/auth/drive.appdata

Fungsi scope dalam bahasa awam: Izin ini hanya memberikan akses ke folder tersembunyi khusus aplikasi (Application Data folder) di dalam Google Drive Anda. Aplikasi hanya dapat membaca, membuat, dan memperbarui berkas cadangannya sendiri di folder khusus tersebut. Aplikasi sama sekali tidak memiliki izin untuk melihat, membaca, mengakses, mengubah, ataupun menghapus berkas, foto, dokumen, atau folder lain di Google Drive Anda.

Alamat email Google Anda hanya dibaca untuk menampilkan informasi akun yang sedang terhubung di aplikasi dan mempermudah proses masuk kembali. Token otorisasi hanya disimpan sementara di memori peramban selama aplikasi dibuka dan tidak disimpan secara permanen di penyimpanan perangkat.

4. Tanpa Iklan, Pelacak, atau Analitik

Aplikasi ini bebas dari segala bentuk iklan, pelacak (trackers), maupun layanan analitik pihak ketiga (seperti Google Analytics). Tidak ada aktivitas penelusuran perilaku atau pengumpulan data statistik penggunaan aplikasi.

5. Cara Menghapus Data

Karena seluruh data hanya berada di perangkat Anda dan di Google Drive pribadi Anda, Anda dapat menghapus data sepenuhnya kapan saja:

  1. Hapus data lokal di perangkat: Hapus data penjelajahan dan penyimpanan situs untuk Mizan Okane melalui pengaturan peramban (browser) Anda. Jika diinstal sebagai aplikasi (PWA), Anda dapat menghapus penyimpanan aplikasi melalui pengaturan perangkat atau melakukan uninstall (copot pemasangan) aplikasi.
  2. Hapus data cadangan di Google Drive: Buka Google Drive di komputer atau browser (drive.google.com) → klik ikon Gerigi (Setelan) → pilih Setelan → pilih Kelola Aplikasi (Manage Apps) → cari Mizan Okane → klik Opsi → pilih Hapus data aplikasi tersembunyi (Delete hidden app data).
  3. Cabut akses aplikasi dari akun Google: Buka halaman keamanan akun Google di myaccount.google.com/connections → pilih Mizan Okane → klik Hapus Akses atau Cabut Akses.

6. Kepatuhan Kebijakan Data Pengguna Google API

The app's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
